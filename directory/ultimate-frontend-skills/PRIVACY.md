# Ultimate Frontend Skills (directory edition) privacy

This edition is instructions, reference text and copy-in files only. It runs no
code of its own, has no hooks, reads no credentials and sends nothing anywhere.
Claude reads and writes files in the project you are working in when you ask it
to build or review a site. What you write in the conversation is handled by
Claude under Anthropic's own terms and privacy policy.
