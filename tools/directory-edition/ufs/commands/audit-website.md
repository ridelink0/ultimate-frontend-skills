description: Review an existing website against the studio checklist, by reading its files
argument-hint: "<site folder>"
---

Use the `ultimate-frontend-skills` skill. The folder to review is: $ARGUMENTS

This edition has no audit script, so the review is by reading. Go through the
site's HTML and CSS against `references/checklist.md`, `references/tells.md`
and `references/copy-tells.md`, and against the skill's "The rules that do the
work". Fix every error and every warning worth fixing, then say in two or three
sentences what you changed and what is left, with the paths. Never report an
automated audit as run.
