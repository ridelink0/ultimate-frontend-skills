# Ultimate Frontend Skills, directory edition

Build cinematic, editorial websites, app screens and game start screens the way
an award-winning studio does: a pinned art direction (editorial serif
typography at real optical sizes, warm-neutral and near-black grounds,
cinematic imagery, layered scroll parallax, exploded technical views), a
corpus of award-winning reference sites to decide against, and a copy-in CSS
chassis, motion runtime and section library that Claude writes into your site.

This edition is Markdown and JSON only. It has no hooks and no scripts, and it
reads nothing on your machine outside the project you are working in. The
full edition, with the scaffolder, the audit, the headless render check, the
verify verdict, Blender, image and video tools, is at
https://github.com/ridelink0/ultimate-frontend-skills.

## Use

Ask for a website, a landing page, an app screen or a game start screen, or
type `/ultimate-frontend-skills:webdesign <brief>`. `/ultimate-frontend-skills:audit-website <folder>`
reviews an existing site by hand against the checklist.

## Skills

- `ultimate-frontend-skills`: the house style and the build route.
- `ui-pro-max`, `terminal-ui`, `sound-design`, `claude-dashboards`,
  `claude-motion`, `remotion-video`, `deep-research`, `link-preview`: the
  surfaces next to a website.

This folder is generated from the sources in the repository;
edit the sources, not these files.
