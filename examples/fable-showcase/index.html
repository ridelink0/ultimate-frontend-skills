Made with Fable 5.1 and the Ultimate Frontend Skills plugin

This is not Anthropic's page. It is a recreation of the Claude Fable 5.1 launch page, built on 14 September 2026 with the Ultimate Frontend Skills plugin, to find out whether its pipeline can produce the page it was measured from.

[1]Introduction

What this is. The five headings on this page are the five entries in the original's contents list, kept so the dot-leader index in the hero has real targets. Everything under them is a note about how this recreation was built. None of it is Anthropic's text, and no claim about either model is made here.

What was copied. The layout numbers only: a 68px solid header, a hero at 87vh, a 13px eyebrow tracked at +0.16em, a two-line serif title at about 76px with the second line pushed 150px right, a 15px contents list, a 28px lede on a 640px column, and body text at 18px with a 1.55 line height. Those came from the plugin's own teardown of the original, not from its stylesheets.

What was not. The wordmark, the prose, the benchmark charts, the bird, and the testimonials. A recreation that carried those over would be a copy, and a copy tests nothing.

[2]A new performance frontier

Not a model benchmark. Nothing on this page measures a model. The heading is here because the original's contents list has it at [2], and the plugin's audit fails a page whose index points at anchors that do not exist.

What was measured instead. The page itself. The plugin's verify command runs the source audit, a headless-browser render at 1440 and 390 pixels, the quality budgets, and the security scan, and returns one exit code. The quality pass watches frames for four seconds under a driven scroll and reports forced layouts, layout shift, idle libraries, and the type scale as painted. The results are in the build notes shipped beside this file.

The sky. The hero is the plugin's sky.js engine: one WebGL sphere with a hand-written fragment shader, a canvas of blurred branches in the lower corners, and three palette buttons that set a weight vector the render loop eases every frame. Clicking a dot does not swap an image. It re-lights the scene.

[3]Scientific research

Not protein design. The original's third section is about research done with the model. This one is about the research done to build the page, which was reading two files: the plugin's teardown of the original's shipped bundles, and the showcase note that corrects four things in that teardown.

What those files know. That the original hero is a three.js scene and not a photograph; that its three dots blend a weight vector barycentrically rather than crossfading assets; that its depth of field is a 72-tap circular bokeh rotated per pixel; and that its clouds thin behind the headline through a shelter uniform rather than a scrim. The plugin's engine reproduces the first two. It does not reproduce the last two, and the notes say so.

What was looked at. The live page, rendered by the plugin's own look command at 1440 pixels, side by side with this one. Where the two differ is written down in the build notes rather than smoothed over here.

[4]Safety, security, and alignment

Not model safety. No safety evaluation of any model appears on this page. The heading is the original's; the content is the page's own.

What ran. The plugin's security command reads the build directory for secrets, environment files, served source maps, forms that post personal data over GET or plain HTTP, CDN scripts with nothing pinning them, and quiet disclosures such as a developer's username in a shipped path. This page has no form, no key, and one CDN dependency, three.js, pinned to an exact version in the import map.

What it cannot see. Whether security headers arrive from a host, because this page has no host. The plugin's reference says to check that with curl after a deploy. There was no deploy, so that check did not run.

[5]Claude Mythos 5.1

Nothing to report. The original's fifth section describes a second model. This recreation has nothing to say about it, and writing something to fill the space would be exactly the kind of invented specific the plugin's rules forbid. The section is here so the index is complete, and it ends here.

[+]About this page

Purpose. A test of the Ultimate Frontend Skills plugin, using the page it was built around as the target. The deliverable is not this page but the build notes next to it, which list every command run, its exit code, what the plugin did well, where it fell short, and what had to be written by hand.

Hand-written here. The article layout, the run-in labels, the tick-mark rail at the left edge, and the credit line in the hero. The plugin's section library had no article template, so those four are site.css and plain markup.

A recreation built to test a plugin. Not affiliated with Anthropic.
